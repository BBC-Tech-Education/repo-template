# lib

Put your own reusable code here, one folder per module, named exactly like the class, e.g. `lib/Motor/Motor.h` and `lib/Motor/Motor.cpp`. PlatformIO finds and builds them automatically.

`RobotConfig/RobotConfig.h` is already here: every pin and calibration number for your robot goes in it.

Libraries from the internet don't go here. Add them under `lib_deps` in `platformio.ini` instead.
